# 战争雷霆 · 导弹规避战术 3D 仿真（wt-missile-simulator）

> 可**实时操控**的空空导弹对抗 3D 仿真：单向拦截 + 玩家 vs AI 对抗双模式，
> 63 枚真实 datamine 导弹、DEZ/NEZ 空战决策算法、合成音效。
> **纯前端、双击即玩、离线可用、零依赖安装**。

**核心特性**

| | |
|---|---|
| 🎮 双模式 | 单向拦截（来袭弹→我机→发射拦截弹）/ 对抗模式（玩家 vs 敌机 AI，互射+自动规避） |
| 🚀 63 枚真实导弹 | 参数整理自 War Thunder datamine（分级固体火箭 / 离架延迟 / 过载包线） |
| 🧠 敌机 AI | DEZ 动能规避（Alkaher 2015）+ 比能量决策 + 上高回头 + "转向敌机·保持距离"poke 策略 |
| 📊 物理内核 | Dagor 大气模型、3DOF 比例导引、SEP 能量机动、法向过载（重力参与转弯） |
| 🔊 合成音效 | 发射 / 爆炸 / RWR 告警（越近越急）/ 发动机随速（Web Audio，零音频文件） |
| 🧪 130 项无头回归 | `node tools/smoke-test.js` 一键验证（物理锚点/论文锚点/行为锚点） |

建模思路参考 [skyking882/missile_sim](https://github.com/skyking882/missile_sim)
（War Thunder datamine 参数 + 比例导引 + 分级火箭 + Mach 阻力模型），
弹体参数取自其整理的 WT datamine 数据（AIM-9L / PL-8 / R-60 / AIM-120A），
但本项目是独立编写的**实时交互**版本（简化动力学，非逐帧复刻游戏求解器）。

📖 **模块结构 / 核心原理 / 状态机**：见 [ARCHITECTURE.md](ARCHITECTURE.md)

## 快速开始

**方式一（推荐）**：双击 `启动.bat`，或直接用浏览器打开 `index.html`
（Three.js 已本地化在 `lib/three.min.js`，无需联网、无需安装依赖）。

**方式二**：本地服务器方式（行为完全一致）：

```powershell
cd wt-missile-simulator
py -m http.server 8080     # 或 python -m http.server 8080
# 浏览器打开 http://127.0.0.1:8080
```

## 操控

| 按键 | 动作 |
|---|---|
| `S` / `↑` | 拉杆（正过载，最大 +9G，默认） |
| `W` / `↓` | 压杆（负过载，最大 -4G，默认） |
| `A` / `←` | 左滚转（默认 180°/s） |
| `D` / `→` | 右滚转 |
| `SHIFT` / `CTRL` | 油门增/减 SEP（仅"简易气动"飞机模型） |
| `C` | 切换视角：追尾 → 座舱 → 导弹 → 自由环绕 |
| `P` | 暂停 / 继续 |
| `空格` | 发射导弹（对抗:打敌机 / 单向:拦截来袭导弹） |
| `R` | 重置 |
| `F` | 对抗模式切换锁定目标（敌机 ↔ 最近导弹，需勾选【允许拦截对方导弹】） |
| 鼠标 | 自由视角下拖拽旋转、滚轮缩放 |

**机动要领**：本模型中拉杆方向跟随机体纵轴 —— 先**滚转**把需要的转弯方向
（机翼上抬的方向）摆到位，再**拉杆**，即可向任意方向急转；
"压杆"产生负过载可快速下沉重心线（防御性俯冲/上下颠簸）。

## 可设置参数

**导弹来袭条件**（实时生效于下次发射）：

- **来袭距离** 0.5 – 40 km
- **导弹初速** Mach 0.8 – 3.0
- **导弹高度** 0.2 – 15 km
- **来袭方位角** 0° = 迎头 / 90° = 正侧向 / 180° = 尾追（0–180° 连续可调；
  **水平面投影**，以机头水平航向为 0°、向右为正，与 RWR 同手向）。
  RWR 目标标记（导弹=圆圈+字母、敌机=菱形 E）同样按水平面投影显示：左转时导弹相对方位向右移，大坡度机动时显示不退化。
  RWR **径向 = 弹目距离（等比/线性刻度）**：径向与距离严格成正比（`r = R·距离/60km`），
  5 km 环 = R/12、20 km 环 = R/3、60 km = 外圈；告警符号为**绿色 M + 外圆**
  （外圆半径 = 5 km 环半径），M 旁标注距离 km 数，`^` / `v` 表示导弹在本机上方 / 下方；
  方位线上另有红 N（NEZ）/ 绿 D（DEZ）动态刻度 —— **仅滑行段**（导弹发动机关闭后）显示
  （论文语义：DEZ 面向能量耗尽型滑行导弹；助推段显示"滑行段生效"提示，
  恒速模式/死弹/脱锁不显示），并可在"显示选项"中开关
- **初速偏角**：导弹初速与来袭方向（瞄准线）的水平夹角 −90°~+90°（模拟**斜射**/离架偏转），
  发射后由引导自动修正；连发时每发独立按该偏角出膛
- **发动机模型**：`推进/阻力（半经验）`（分级固体火箭 + 1943 Cx(M) 阻力）或
  `恒速（纯运动学）`（保持初速，纯比例导引几何对抗）
- **导弹模型**：`细化气动`（默认：AoA 状态 + α² 诱导阻力 + 舵面迎角/过载限制）或
  `基础`（质点 + 过载直转）
- **连发**：连发数量 1–8 枚 + 发射间隔 0.5–30 s（面板可设）——多发逐次出膛，
  每发独立弹道/事件（各自 CPA/脱靶量），任一发命中即算命中；每发的**飞行总距离**实时显示
- **高级参数**：质量、弹径、CxK 阻力标度、助推/巡航级时间-推力-燃耗、
  导弹最大过载、PN 导航系数 N、导引头角速率、引信半径、寿命、**离架延迟 timeOut**、中段爬升

**对抗模式**（⚔ 面板切换）：双机空战 —— 我方手动驾驶（**空格**发射我方导弹、**R** 重新开始），
敌机可定制：**主动策略**（直飞 / 朝向玩家飞行 / 转向敌机·保持15km / **保持10km（默认）**——外圈保持
poke 姿态持续骚扰、压近则拉开，收敛于敌机 NEZ 外界）+ **规避策略**（复用自动战术库：
最大G定常盘旋/置尾/置尾平飞/DEZ动能规避/**垂直导弹速度矢量**，默认 **DEZ 动能规避**）+ 敌方导弹型号/初速与**发射间隔**。敌机高度可独立配置（km）。我方导弹可选任意预设或
**自定义（当前高级参数）**。双方均可勾选**无敌**（默认关）：被命中只计数不结算，
面板实时显示 **命中 / 被命中** 计数与敌机状态。对抗面板参数（无敌勾选/敌方导弹/初速/
发射间隔/策略/我方导弹）**实时生效**——开局后再修改也立即应用，无需重新切模式。RWR 显示
敌方导弹红 `M` 与敌机红菱形 `E`（我方导弹不上 RWR；以我机头水平航向为基准）。3D 视图中
敌机为**红色尾迹** + **绿色方框**位置标记 + 绿框状态标签（距离 / 速度·马赫 / 高度）；
导弹尾迹按动力段分色（**黄 = 动力段、黑 = 出动力段**）；
**【音效】**（Web Audio 合成、零音频文件）：发射 whoosh / 爆炸 boom / RWR 告警蜂鸣
（≤19km 雷达弹，越近越急）/ 发动机轰鸣（随速），显示选项可开关；
**每发导弹有自己的红色引导线**（连线 目标—导弹，弹对弹拦截时连线两弹，随目标实时移动）；
右上角过载-马赫曲线显示**最近威胁导弹**的包线与实时工作点。敌方按**最近导弹**决策：
最近导弹存在且能量（`e = V²/2 + g·h`）未被拖垮 → 对**最近导弹**执行 DEZ 规避
（转向完成后若未达最大表速则**略微下高 γ≈−3° 冲刺**，达标后平飞）；
最近导弹**为空**（或能量低于自身）→ 先**平翼上高（+2 km）再最大过载回头**
（指向主动策略目标方向：朝向玩家→指向玩家 / 直飞→回先前航向），随后执行主动策略
（过渡限时 30s 收尾，绝不卡死不回头）。
导弹尾迹按动力段分色（黄 = 动力段、黑 = 出动力段），**尾迹容量按预计存活时间申请**
（航渡估算=弹目距离/平均闭合速度×1.5 余量、上限为寿命；采样按**仿真时间** 30Hz——高刷屏不加速消耗）
（30Hz 采样 × 寿命，动力段按推进时间单独小容量，既保全航程又省内存）。
默认双方 **AIM-120D**、初始 **25 km / 5 km**。

**空格 = 发射导弹**（对抗模式锁定**敌机**；单向模式**锁定最近来袭导弹** —— 我方拦截弹，
弹对弹近炸，命中后来袭弹记为"被拦截（我方拦截弹击毁）"）；**R = 重置**。
**发射约束**：目标须在**机头前半球**内才能发射（后半球提示"目标不在前半球"）。
**目标切换（F）**：勾选【允许拦截对方导弹】（默认关）后，对抗模式按 **F** 在"锁定敌机 ↔
锁定最近导弹"间切换（空格按当前锁定目标发射，拦截计入"命中/被命中/**拦截**"三元计数）；
**未勾选时任何模式都不得拦截导弹**（单向模式空格拦截同样被禁用）。导弹池上限 **1024** 发
（环形复用：满员后覆盖最旧槽位；死弹尾迹保留不回收）。

## DEZ 动能规避算法（Alkaher & Moshaiov, JGCD 2015）

实现论文《Dynamic-Escape-Zone to Avoid Energy-Bleeding Coasting Missile》
（J. Guidance Control Dynam., DOI:10.2514/1.G000776）的完整算法 ——
`js/dez.js`（DER/NEZ 解算器）+ 战术「DEZ动能规避（Alkaher2015）」+ HUD/RWR「NEZ/DEZ」双边界动态决策支持：

**① 最优规避策略（论文 Eq.25，零和微分对策鞍点解）**：tail-steering（机尾转向）——
最大过载把**机尾对准弹目视线**（σe→180°，把迎头/侧向几何强制转为尾追），
偏角清零后**定高直飞**，靠滑行段导弹的能量耗尽（减速到目标速度以下）脱离
（missile outrunning）；追击方对应最优解为 nose-steering（机头对视线）。

**② 动态逃逸距离 DER（论文 Eq.26-29）**：

```
RProj_DEZ = ρp(|sinΔχp| − |Δχp|) + ρe(|Δχe| − |sinΔχe|) + R_S&Lp(vp→ve) − ve·tf
R_DEZ     = RProj_DEZ / cos(|Δχp| − |σp|)      （当前 LOS 投影，实现取 1）
ρi = vi²/(g·ni_max)   Δχ = 转向最终 LOS 轴的转角   R_S&Lp = 导弹滑行能量航程
```

**③ 决策律（论文 Eq.1）+ NEZ 双边界**：`Rpe > R_DEZ` → 在动态逃逸区内，施行上述最优规避**可保证脱离**；
`Rpe ≈ 1.25·R_DEZ`（含论文不确定性裕度）→ **最晚脱离时机**，战术自动启动；
另解算 **NEZ（不可逃逸区/必杀区）**边界 —— 导弹侧保守（全程按 0.35·n_max 平均机动计诱导阻力），
`Rpe ≤ R_NEZ` → 末端必杀区。三区动态判定：

| 区 | 条件 | 含义 | 颜色 |
|---|---|---|---|
| 安全区 | Rpe > 1.25·R_DEZ | 动能规避可保证脱离 | 绿 |
| 立即脱离! | R_DEZ < Rpe ≤ 1.25·R_DEZ | DEZ 裕度带，战术自动启动 | 黄 |
| 对抗区 | R_NEZ < Rpe ≤ R_DEZ | 胜负取决于双方战术 | 橙 |
| NEZ 内 | Rpe ≤ R_NEZ | 末端必杀区，只能硬躲 | 红 |

**动态显示**：HUD「NEZ/DEZ」实时数值；RWR 沿导弹方位线显示**红 N（NEZ）/ 绿 D（DEZ）动态刻度**，
随战况实时移动 —— 仅在**语义有效窗口**显示：动力学发动机 + 导弹**滑行段**（无推力）+ 活弹 + 导引头跟踪；
助推段显示"滑行段生效"提示，恒速模式/死弹/脱锁不显示（论文对象是滑行段能量耗尽型导弹）。
导弹浮动信息框内也有分区状态。显示选项（面板可开关）：
红色空心三角标记 / 导弹信息框（关闭则只显示在上方面板）/ 红色引导线 / NEZ/DEZ 刻度 /
**过载-马赫曲线**。

**仿真验证**（回归组"DEZ 动能规避（Alkaher2015 论文验证）"，复刻论文情景：
20000 ft、目标 Ma1、纯滑行导弹 M4.5→M1）：

| 检验 | 结果 |
|---|---|
| 滑行能量航程 M4.5→M1 | 43.4 km / 66 s |
| 初始 R_DEZ（迎头 30 km 处） | 26.2 km（处于 DEZ 内 ✓） |

## 物理模型（简化动力学）

**飞机**（3 自由度质点 + 四元数姿态）：

- 恒定马赫数飞行：`V = M · a(h)`，速度恒沿机轴（零侧滑/迎角简化）
- **大气模型 = DagorEngine 精确移植**（`gamePhys/props/atmosphere`：单一 4 次多项式、
  0–18300 m 设计域、18.3 km 以上 1/h 尾部，`a = 20.1·√T`、ρ0 = 1.225）——与 WT 逐位一致
  （12–17 km 密度比真大气高 3–7% 等"怪脾气"照抄，工程复盘见提交历史）
- **简易气动（能量/SEP）模型**（可选）：速度成为能量状态，`d(h + V²/2g)/dt = SEP`；
  SEP 由油门（SHIFT/CTRL）给定、按过载线性扣除机动能量损失
  （`SEP = SEP_油门 + gLossMax·(|n|−1)/(n_max−1)`），动能↔势能实时互换
- 拉杆/压杆 → 法向过载指令 `n`（限幅 +9G/-4G，过载速率限制 30 G/s）
  → 俯仰角速度 `ω = n·g / V`
- 滚转 → 绕机体纵轴角速度（默认上限 180°/s，带角加速度限制）

**导弹**（3 自由度质点 + 比例导引）：

- 制导：`a_cmd = N · Vc · (ω_LOS × v̂)`，`ω_LOS = (r × ṙ) / r²`，`Vc = -(r·ṙ)/|r|`
  （与 missile_sim 的 PN 实现一致，N 默认 4）
- 导引头角速率限制（datamine `seeker.rateMax`：AIM-9L 22°/s、PL-8 20°/s、
  R-60 30°/s、AIM-120A 60°/s）：目视线角速度持续超限 1.5 倍约 0.6 s
  → 导引头丢失目标（脱锁后惯性飞行）——高角速度穿插是最主要的规避机制
- 横向过载限幅（datamine `reqAccelMax` / 两段式包线：低速升力链 + finsLatAccel 平台），
  重力补偿并入横向指令
- **中段爬升（高抛）**：`loft` 弹在远半程且 tgo>12 s 时由**爬升角程序**接管垂直面 ——
  爬升角 γ 一阶趋向 `loftAngleDeg`（PN 垂直分量被覆盖、水平导引保持），近半程自动转
  末端俯冲。旧实现仅叠加 0.35G 偏置、会被 PN 碰撞航线保持抵消（50 km 顶点仅 ~160 m）；
  顶点由 **PD 顶点伺服**瞄准 `h0·(1 + 0.35·loft/22°)`（按游戏实测校准：
  AIM-120D 10 km/M1.6 迎头发射顶点 ≤13.5 km，本实现 13.67 km），末端因高度换速度能量更足
- 推进：分级固体火箭（推力 + 秒耗质量）
- 阻力：`D = ½ρV² · CdA(M)`，`CdA(M) = S_ref·翼面倍数·CxK·Cx(M)`，
  `Cx(M)` 为 1943 年阻力律（×1.10）跨/超音速插值表
- **诱导阻力（升致阻力）**：拉过载即耗能 —— `D_i = k·(n·m·g)²/(q·S)`，
  `k = 1/(π·AR·e)`（AR≈4、e≈0.8，弹体+舵面组合有效值，按拦截时间线校准）；
  气动模型按引擎极线 `cx = cd0 + cy²/(π·λ)`（λ=3 引擎默认，`polares.cpp`）
  取 `CxAoA = k_L²/(π·3)`；升力系数以 4 失速截断（"恒速（纯运动学）"模式不含此项）
- **离架延迟**（`guidanceAutopilot.timeOut`，datamine 实测）：发射后延迟段内**保持直飞**
  （无引导 / 无升力补偿，仅受推力与重力），到期开启引导 —— 39/63 款有实测值
  （R-73 0.15 s 最短 ~ AIM-26B 2.0 s 最长，Fakour-90 1.5 s）；无 timeOut 字段的 22 款按
  `timeToGain` **零增益平台**映射（R-27 系 0.35 s、AIM-54 系 2.5 s、Skyflash/7E/7D 1.8 s、
  PL-12/R-77 系 0.3 s 等；AIM-7F/7M 的 timeToGain 无零增益平台 → 0）——
  两套编码在全库 706 个 blkx 中完全互斥，系同一"离架延迟"的不同格式
- 终止事件：近炸引信（≤3 m 记直接命中）/ 脱靶（弹目距离拉开 400 m）/
  超时（寿命）/ 动力耗尽（<180 m/s）/ 撞地

### 细化气动模型（AeroMissile，面板「导弹模型」可切换，默认启用）

- **迎角状态 α⃗ + 舵面力矩二阶动力学**（finAOA / fin面积 / 质心距离直接挂钩机动性）：
  `α̈ = ω_n²·(α_cmd − α) − 2ζ·ω_n·α̇`，其中 `ω_n = √(q·S_fin·Cn_fin·l / I)`
  —— 舵面面积（`wingAreaMult`）越大、力臂（`distFromCmToStab`）越长、动压越高，
  过载建立越快；弹体惯量（`I ≈ 0.02·m·L²`）越大越迟钝
- **非线性升力**：`Cy(α) = k_L·α` 线性段 + `CyMaxAoA` 失速平台（α 超过失速迎角后升力不再增长）
- **迎角诱导阻力**：`D_i = q·S·CxAoA·α²` —— 拉大迎角即大量耗能（能量战的核心机制）
- **舵面限制（datamine 实测）**：迎角 ≤ `min(finsAoaHor, finsAoaVer)`；
  可用过载 = **两段式包线** `n_max(M) = min( q·S·k_L·α_max/(m·g), min(nMax, finsLatAccel) )`
  —— 低速段 ∝ M²（受 fin 面积/迎角限制），高速段平台（受 finsLatAccel 限制）
- **过载-马赫曲线**：界面右侧上方图表绘制**实时包线**（按当前高度/当前质量计算，**随爬升/燃耗浮动**
  ——正是高度与质量对机动性影响的直观体现；标题实时标注 @高度·质量、右上角有浮动说明；
  橙 = 低速升力链段 / 绿 = finsLatAccel 平台段，**黄色虚线 + 圈 = 转折马赫**
  （升力链 = 平台交点，标注 `M值 平台过载G`，低于该马赫机动性开始下降），红点 = 当前实际工作点、白色虚线 = 当前马赫），
  "显示选项"可开关
- **升力斜率标定**：`k_L = finsLat·m0·g / (qRef·S·α_max)` —— 升力链与权限平台在参考动压
  `qRef = ½ρ0·VRef²`（VRef = `baseIndSpeed` 指示空速 1800 km/h）处相交。
  ⚠️ datamine 的 `CyK` **不作升力斜率使用**：其语义与本模型"每弧度升力斜率"不等价
  （麻雀家族共享 CyK=3.5 家族默认值；直接代入会把 AIM-7M 的机动性饿死到 ~2G/M1.8，
  与 finsLatAccel=29G 标称严重矛盾），仅作参考保留
- **datamine 缺失项的文档化回退**（2.59.0.7 中 CxAoA / CyK 未提供）：
  `CxAoA = 0.1·k_L²`（与基础模型的诱导阻力标定严格一致）
- HUD 新增「导弹AoA °」实时显示；舵面力臂 / PID 参数已入库供后续 5DOF 姿态环使用

### 已知简化与限制

- 飞机为"速度沿机轴"的质点模型：无迎角/侧滑、无能量管理（速度恒定）、无推重比/阻力
- 导弹为 3 自由度：无姿态环/PID 舵机；诱导阻力按"过载-升力系数"近似（无显式迎角状态），
  可用过载按动压简化衰减
- 导引头建模简化：仅角速率上限 + 超限丢失（无距离门/多普勒/地杂波）
- 无对抗措施（箔条/红外干扰弹）
- 目标是**战术定性对比**（哪种规避更有效），不是游戏逐帧数值复刻
